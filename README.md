# Cage Kings (test build)

**Cage Kings** is a 2D side-view MMA fighting game. It's written in plain HTML5 canvas and vanilla JavaScript, with no build step and no dependencies.

> ⚠️ **Test build.** This is an early milestone-1 build for playtesting. Expect rough edges in balance, animation and UI.

**Play:** https://avrgnewb1.github.io/cage-kings/

- **Modes:** Quick Fight (10 signature fighters, 3 difficulties) and Career (create a fighter, train, take offers, climb the top 10, win the belt). Career progress saves in your browser's localStorage.
- **Keyboard:** A/D move · S low · W up · J jab · K power · L kick · U grab · I takedown · Space block · Esc pause. Button labels change with position in the clinch and on the ground.
- **Touch:** a virtual stick plus context buttons. Play in landscape.

All fighters, promotions and names are fictional.

To run it locally, serve this folder (for example `python3 -m http.server`) and open it in a browser.
